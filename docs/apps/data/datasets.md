# Datasets

**Datasets** are the virtual folders of Arcsecond.local: they group data files
that share a common source or interest, so you can browse, manage and download
them together. Every file you upload or that Arcsecond.local indexes belongs to a
dataset.

:::info
Detailed documentation is on its way. You can already create datasets and upload
into them from the [CLI](/cli/upload).
:::
