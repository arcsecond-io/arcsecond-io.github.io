# External Storage — FTP

Arcsecond.local can attach an FTP server as a read-only external storage and
index the FITS/XISF files it serves. For anything carrying credentials over an
untrusted network, prefer [SFTP](./external-storage-sftp.md).

:::info
Detailed step-by-step configuration is being documented.
[Contact us](mailto:team@arcsecond.io) if you'd like to attach an FTP server in
the meantime.
:::
