# Pricing

> Two procurement paths for the same observatory system.

Arcsecond.local can be structured either as a **project-funded deployment** or as
an **annual operations agreement**, depending on how your observatory budgets
software. It is the same system, the same code and the same features either way —
only the procurement shape changes.

## Project-funded deployment

*Grant-based.*

Best suited to grants, institutional rollouts, and telescope upgrade projects: an
initial deployment budget for setup and integration, followed by a lighter yearly
maintenance agreement.

## Annual operations agreement

*Subscription-based.*

A single recurring yearly budget line covering software maintenance, support, and
continued operational evolution — for observatories that prefer one clean
operational cost.
